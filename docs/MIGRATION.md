本次没有重新初始化 storage，没有替换 profile，也没有删除旧 answers、memories、history、supplement 或附件。备份 schemaVersion 仍为 1；学习记录内部新增 scopeVersion:2；诊断包独立使用 schemaVersion:2。

更新前在原插件设置页导出完整备份。用相同的安装目录覆盖代码并重新加载扩展；不要删除原扩展。跨路径/电脑安装时用原有备份导入。完整备份可能含 API Key，只在本地保存。

## 学习适用范围

- 新规则按 platform + siteScope（域名/租户）+ pageType + 字段身份隔离；固定回答还按重复行区分。
- 值转换继续保存“资料原值→目标值”；资料变更后原值不匹配就不会使用旧转换。
- 资料映射只存语义路径，实际值每次从当前资料取。通用引擎明确可匹配的本地资料优先于固定历史回答。
- 旧记录有确定 host、可确定 section 页面类型且不存在租户歧义时，限制在同来源下兼容读取。缺来源或缺页面类型的记录仍显示、备份，但不自动套用；用户在真实页面重新“记住”，或显式绑定范围。
- 不再把某平台同名题的答案自动套到另一网站。旧测试若期待该行为，需要在本地改成隔离契约，不要为了让旧断言通过而恢复跨站读取。
- 原 AI 缓存和选项缓存保留，新增带 v2 作用域的键；旧缓存不会覆盖新作用域结果。

## 管理接口

现有设置页继续查看/删除、通过完整备份导入导出学习数据。显示域名/租户和 pageType。独立的规则编辑与共享操作有后台接口，精细 UI 留给下一轮本地开发：

| 消息 | 参数 | 行为 |
|---|---|---|
| MEM_EDIT | id, to | 修改固定答案或资料映射，保留历史 |
| MEM_BIND | id, context:{host,platform,pageType,siteScope} | 为旧规则复制一个明确范围的新版本，保留旧记录 |
| MEM_PROMOTE | id | 显式复制类型级共享资料映射；拒绝公司问题、固定答案 |
| MEM_DELETE | id | 删除指定规则 |
| MEM_SAVE | items | 写入学习层生成的记录，保留历史 |
| DIAG_EXPORT | 无 | 导出脱敏诊断包 |

新增 UI 应走这些消息，不直接改存储。需要同类共享时先确认该字段在不同公司中的含义相同。当前只有资料映射允许提升；特殊控件操作不作为用户数据中的可执行脚本。

## 回退

切回旧代码不会删除资料。3.8 不理解 v2 隔离语义，因此推荐先导出当前备份，再恢复升级前备份；不要在旧代码上继续学习后把新旧结果混写。备份导入会完整替换本地数据，这是原有行为。
